# ilakochi_v2

Official website for **ILA KOCHI (ഇല കൊച്ചി / Ila Kochi Kitchen)** — Authentic Kerala Seafood and Living Banana Leaf Dining located near Metro Pillar 350, Pathadipalam, Edappally, Kochi.

## Features
- **Cinematic Culinary Reel:** Authentic vertical video showcase of live tawa sizzle and banana leaf sadhya with audio controls.
- **Kerala Coastal Heritage:** Editorial storytelling celebrating the ancient custom of eating hot meals off living plantain leaves.
- **Harbour to Hearth Journey:** 3-step culinary process from dawn boat catch to clay hearths.
- **Interactive Menu & Dish Modal:** Categorized menu filters, search, spice levels, and direct WhatsApp pre-orders.
- **Table Reservation System:** Seamless table booking inquiries integrated directly with restaurant management on WhatsApp.
- **Verified Social Proof:** Google 4.0 ★ (700+ reviews) customer experiences.
- **Location & Direction Guide:** Interactive Google Maps embed with landmark references by Metro Pillar 350, behind Unimoni.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP + ScrollTrigger
- **Icons:** Lucide React
